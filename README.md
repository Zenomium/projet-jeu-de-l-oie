# Jeu de l'Oie sur terminal

## Langages utilisés : **C**

## Nombre de joueurs : **2** à **4** joueurs

## Fonctionnalités :
- **Oie** : Vous avancez à nouveau du même nombre de cases.
- **Raccourci** : Vous prenez le raccourci et vous déplacez en case 16.
- **Trou** : Vous devez attendre qu'un joueur prenne votre place.
- **Prison** : Vous êtes en prison et devez attendre qu'on vous aide à vous évader.
- **Hôtel** : Vous êtes à l'hôtel et passez votre tour deux fois.
- **Labyrinthe** : Vous êtes dans un labyrinthe et reculez de 13 cases.
- **Mort** : Vous avez rencontré la tête de mort et retournez à la case 0.

## Compilation et utilisation du programme :

**Compilation** : clang -std=c17 -Wall -Wfatal-errors jeudeloie.c -o jeudeloie -lm

**Execution** : ./jeudeloie
